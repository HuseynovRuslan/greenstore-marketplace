# Variant 2 mockups

`Header-Hero.dc.html` (1440 px) and `Header-Hero-Mobil.dc.html` (390 px) are the approved Variant 2 mockups for the
home page.

**Renamed after the mockups were made (5 November 2026):** the section the mockups call «Bağ vitrini», with the
badge «Vitrin» and a leaf icon, is «Önə çıxan elanlar» on the site. The menu link is «Önə çıxanlar», the card badge
is «Önə çıxan», and the icon is a rocket (lucide `Rocket`) everywhere: the header link, the section heading and the
badge. The mockup files are kept as they were delivered; where they disagree with the site on this name, the site is
right.
